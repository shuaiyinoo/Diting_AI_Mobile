# Diting AI Mobile v1.0.0 更新

> 首个正式版本。Diting AI Mobile 是 Diting AI 的移动端客户端，基于 **Vue 3 + Capacitor 8** 构建，同时产出 **Android / iOS** 双端安装包。核心能力：**手机远程投屏控制电脑桌面**（一键直连 / 会话码连接、WebRTC 实时画面、完整手势与键盘输入、旋转全屏），以及 **Chat / Agent 移动端对话**框架。

---

## ✨ 新功能

### 🔐 账户与登录

- **Cloud 账户登录** — 邮箱 + 密码登录 Diting Cloud，Token 通过 Capacitor `Preferences` 持久化加密存储，冷启动免登录直进主页。
- **路由守卫** — 未登录自动重定向到登录页，登出后清空会话状态。

### 🏠 主页框架（AppLayout）

- **三 Tab 导航** — Chat / Agent / 设置 三个主功能，底部菜单（TabBar）+ 内容区切换，顶栏随当前 Tab 显示标题与副标题。
- **响应式双布局** — 按视口宽度（≥768px）自动切换：竖屏手机为**底部横排菜单**，折叠屏 / 平板 / 大屏为**左侧竖排菜单**，安全边距（刘海屏 / 手势条 / 挖孔屏）全适配。
- **共用投屏连接** — 远程投屏组件挂载于布局层，Chat 与 Agent 之间切换 Tab 连接不中断，共用同一条投屏链路。

### 📱 远程投屏控制（核心功能）

- **两种连接方式**：
  - **一键投屏** — 自动发现当前在线设备并通过 Wake 令牌直连，无需输入任何码。
  - **会话码连接** — 输入桌面端生成的 6 位连接码接入指定设备。
- **内嵌投屏组件** — 投屏画面内嵌在 Chat / Agent 内容区上半部分（宽度铺满、高度随画面比例自适应），支持**收起**（收起后顶部显示"远程屏幕"摘要条，点击展开，连接保持不断）。
- **旋转全屏** — 小屏点击全屏后组件整体旋转 90°，**只占顶栏与底部菜单之间的中间区域**；App 布局保持竖屏不重排，手机横过来即正立观看（状态栏在左、手势条在右），全屏下完整保留画质 / 分辨率 / 多屏切换 / 控制条。
- **手势操作** — 单指点击（左键）、长按 / 双指点按（右键）、拖拽移动光标（125Hz 节流防堆积）、双指滚动（滚轮轴自适应）、捏合缩放；旋转全屏下坐标自动换算，落点精准。
- **远程输入** — 原生键盘输入（实时字符透传、中文输入法合成支持）、专用 Backspace / Delete / Enter 按键、右键菜单、断开连接。
- **画质调节** — 三档画质（低 / 中 / 高）与四档分辨率（标清 480p / 高清 720p / 蓝光 1080p / 原画）实时切换。
- **多屏切换** — 远程设备多显示器时一键循环切换，画面角落显示当前屏幕序号。
- **三级自动重连** — 网络波动快速恢复（ICE restart）→ 重建会话 → 失败态手动重试，弱网环境不断线。
- **UI 隐藏模式** — 一键隐藏全部浮动控件，纯净观看画面，手势仍可操作。

### 💬 Chat / Agent 对话

- **会话列表** — 大屏侧边栏展示历史会话（宽度可拖拽调节、可收起），小屏自动隐藏。
- **消息区 + 输入框** — 底部两行高浮动卡片式聊天输入框，回车 / 按钮发送，Chat 与 Agent 共用。

### ⚙️ 设置

- **连接配置** — 展示 API / STOMP 信令 / TURN 服务器等运行参数（构建时注入）。
- **账号管理** — 当前登录用户信息展示、退出登录。
- **运行环境** — 运行平台（Android / iOS / H5）、原生容器状态。
- **数据管理** — 一键清除本地连接历史。

### 🛡️ 系统级适配

- **Android 15+ Edge-to-Edge** — 适配 Android 15 起强制的全面屏绘制策略，通过 Capacitor `SystemBars` 注入 `--safe-area-inset-*` CSS 变量，状态栏 / 手势条安全避让全机型覆盖。
- **iOS 安全区** — `viewport-fit=cover` + `env(safe-area-inset-*)` 原生适配刘海屏与灵动岛。
- **沉浸模式** — 远程桌面全屏路由页自动保持屏幕常亮 + 隐藏状态栏。

## 🚀 优化

- **Android WebView 渲染兼容** — 规避旋转上下文中 `backdrop-filter` 渲染丢失缺陷，浮动控件统一白色实底 + 边框 + 阴影，选中态主题色高亮，视频画面上辨识度最高。
- **投屏工具条** — 画质 / 分辨率分段选择器、多屏切换、收起 / 断开、UI 隐藏全部保留在浮动层，不打扰画面观看。
- **Web 产物与原生工程解耦** — Vite 构建产物通过 `cap sync` 注入原生工程，`.env.production` 管理环境配置。

## 🐛 Bug 修复

- 修复 Android 15+ 上状态栏 / 手势条与内容重叠无安全距离的问题（三道防线在 Android 15+ 全部失效，改用 SystemBars CSS 变量方案）。
- 修复小屏全屏时旋转组件尺寸取整个视口、遮挡顶栏与底部菜单的问题（改为仅占中间区域）。
- 修复旋转全屏下触摸坐标转置 / 镜像、滚轮轴向错乱的问题（视觉坐标 → 内容坐标换算）。
- 修复旋转全屏下浮动控件（多屏切换 / 显示隐藏）渲染消失的问题。
- 修复切换 Chat / Agent 时投屏重连的问题（组件常驻布局层，连接保持）。
